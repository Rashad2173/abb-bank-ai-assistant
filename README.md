# ABB Bank AI Assistant

A web application that answers questions about **ABB Bank** using the content of
its official website, [abb-bank.az](https://abb-bank.az). Answers are generated by
an OpenAI model with retrieval-augmented generation (RAG): relevant passages are
retrieved from a **Milvus** vector database and the model answers only from them.

> Case study for ABB. The full list of requirements and their status is tracked
> in [REQUIREMENTS.md](REQUIREMENTS.md).

## Scraper highlights

The site is a Next.js application backed by a Strapi CMS. A plain HTML scraper
misses a large part of it — tariffs and interest-rate tables in inactive tabs,
FAQ answers in closed accordions, client-rendered sections and the whole branch
and ATM network. The scraper therefore combines three sources:

* the server-rendered **HTML**,
* the page's **CMS data from the React Server Components payload**,
* the site's own **Server Actions / REST API** for branches, ATMs and terminals.

Result: 7 397 URLs crawled with 0 failures, **4 420 clean documents**
(8.7 M characters, 1 550 FAQ items), **100 % coverage** of the CMS text.
Details and design decisions: [scraper/README.md](scraper/README.md).

## Quick start

Requires Python ≥ 3.10.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt

# Scrape the website → data/abb_pages.jsonl (≈ 30 min, resumable)
cd scraper
python -m abb_scraper run

# Run the tests (from the repository root)
cd ..
pytest
```

## Key decisions

| Decision | Reason |
|----------|--------|
| Milvus as vector database | Case requirement; supports hybrid (dense + BM25) search |
| Embedding model chosen by benchmark on Azerbaijani data | Most of the content is Azerbaijani — accuracy matters more than cost |
| Crawl and extraction as separate phases | Extraction rules can be improved and re-run in minutes without re-downloading the site |
| Repeated content kept once, on the most general page | Prevents duplicate chunks from crowding search results |
