# Evaluation

Every claim about quality in this project is backed by a test set in this folder
and a generated report in `reports/`.

```
evaluation/
├── retrieval/   question sets for retrieval (do the right chunks come back?)
├── guardrail/   question sets for the guardrail (is out-of-scope refused, in-scope answered?)
├── answers/     question set for answer quality (is the final answer right?)
└── reports/     00–07, generated by the commands below
```

| Report | Measures | Set | Result |
|--------|----------|-----|--------|
| [00_data_quality](reports/00_data_quality.md) | scraped text vs. the site's CMS | all 4 223 pages | 99.9 % of CMS text lines present |
| [01_chunk_quality](reports/01_chunk_quality.md) | chunk sizes, structure | 9 604 chunks | none over 512 tokens |
| [02](reports/02_embedding_benchmark.md) / [03](reports/03_embedding_benchmark_set_b.md) embedding benchmark | 3 models × search methods, exact search | retrieval set A / set B (100 + 100) | bge-m3 dense + sparse + reranker: 173 / 200 with all evidence in the top 5, Recall@10 93 % |
| [04_milvus_check](reports/04_milvus_check.md) | the same through Milvus | sets A + B | identical to exact search; HNSW recall 99.7 %; 4–10 ms per search |
| [05_guardrail](reports/05_guardrail.md) | refusals, greetings, no false refusals, no prompt leaks | `guardrail/guardrail_set.json` (64) | 64 / 64 — after tuning the rules on this set |
| [06_guardrail_independent](reports/06_guardrail_independent.md) | the same, written independently and harder | `guardrail/guardrail_set_independent.json` (80) | **80 / 80**; 0 false refusals; 0 leaks |
| [07_answer_quality](reports/07_answer_quality.md) | the final answer, graded against the source text | `answers/answer_set.json` (56) | **54 correct, 1 partial, 1 wrong; 0 invented facts** (first run: 51 / 2 / 3) |
| [08_retrieval_pipeline](reports/08_retrieval_pipeline.md) | query planning (Azerbaijani search, tender filter) on / off | sets A + B, answer set | source page reaches the model: 49 → 51 of 53; Russian 3 → 5 of 5 |
| [09_retrieval_methods](reports/09_retrieval_methods.md) | dense + sparse vs. dense + BM25 vs. all three, full pipeline | sets A + B, answer set | all three: 174 / 200, 52 / 53 — best or equal everywhere |

## Question sets

| File | Written | Evidence |
|------|---------|----------|
| `retrieval/abb_100_soru_kaynakli.md` → `questions.jsonl` | first set, against corpus version `042c420d` | corpus positions, frozen to text |
| `retrieval/question_set_b.json` → `questions_b.jsonl` | separately, from pages set A does not use | URL + verbatim snippet |
| `retrieval/evidence_additions.json` | reviewed equivalent passages for set A | URL + snippet |
| `guardrail/guardrail_set.json` | off-topic, other banks, personal advice, prompt injection, harmful, greetings, legitimate edge cases | expected status (+ refusal reason) |
| `guardrail/guardrail_set_independent.json` | independently, without seeing the prompt or the first set | same format |
| `answers/answer_set.json` | from pages neither retrieval set uses | expected facts + source URL |

## Commands

```bash
cd retrieval
python -m abb_retrieval evalset [--set b]      # map a retrieval set to the current chunk ids
python -m abb_retrieval benchmark [--set b]    # reports 02 / 03
python -m abb_retrieval milvus-check           # report 04 (Milvus running)
cd ..
# with the services running (see services/README.md):
python scripts/eval_guardrail.py                                                 # report 05
python scripts/eval_guardrail.py --questions evaluation/guardrail/guardrail_set_independent.json --report 06_guardrail_independent
python scripts/collect_answers.py && python scripts/answer_grades.py            # report 07 (grades are reviewed by hand)
```
